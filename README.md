# Проект "Виджет успешных операций"

## Описание
Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка

Клонируйте репозиторий.
```
git clone https://github.com/neron262013-sudo/Bank_vidget.git
```

## Использование
- Введите тип и номер карты или счета и получите маску карты или счета. (widget.py)
```
print(mask_account_card("Visa Platinum 7000792289606361"))
print(mask_account_card("Счет 73654108430135874305"))
```

- Вспомогательные функции get_mask_card_number и get_mask_account маскируют номер карты и номер аккаунта. (masks.py)
```
print(get_mask_card_number(7000792289606361))
print(get_mask_account(73654108430135874305))
```

- Форматирования даты из словаря в дд.мм.гг. (widget.py)
```
print(get_date("2024-03-11T02:26:18.671407"))
```

- Отфильтровать по статусу. Можно указать аргумент ключа "state". 
   Если не указать, то state = "EXECUTED". (processing.py)
```
print(filter_by_state([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
                       {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
                       {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
                       {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
                      ))
```

- Упорядочить по дате. По умолчанию аргумент направления сортировки = "убывание", если указать иное, то возрастание.
   (processing.py)
```
print(sort_by_date([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
                    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
                    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
                    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
                   ))
```
